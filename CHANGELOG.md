## [1.0.0] - 2026-11-10

### Added

- Home screen with every Pokémon from PokeAPI in a grid, with search, sort by number or name, and a type filter.
- Pokémon detail page with sprites (front, back, shiny, female), cry, height, weight, abilities, base stats, type matchups and the evolution chain.
- Catch and release Pokémon, and a My Pokédex screen with a caught counter. Caught Pokémon are stored on the device.
- Daily "Who's that Pokémon?" guessing game with hearts and a streak.
- About screen with the unofficial fan project disclaimer and links to the Privacy Policy, Terms of Use and source code.
- Disk cache for PokeAPI responses, to keep the number of requests low.
