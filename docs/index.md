# Pokédex

An Android Pokédex with a daily "Who's that Pokémon?" game, built with Kotlin, Jetpack Compose, Room and PokeAPI.

This is an unofficial fan project. It is not affiliated with, endorsed by or sponsored by Nintendo, Game Freak, Creatures or The Pokémon Company.
